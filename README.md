# iYegen Blog

The official blog of **iYegen** — the iOS app that generates Yealico site rule JSON automatically.

Paste a URL, tap the magic wand 🪄, and get a ready-to-import Yealico rule. No hand-written selectors, no regex, no JSON editing.

🌐 **Live site:** https://pescadocamarao.github.io/iyegen-blog/

iYegen is currently in development, heading to the App Store.
