Create Yealico rules.
Without writing JSON.

iYegen is an iOS app that turns any website into a ready-to-import Yealico site rule. Paste the URL, tap the magic wand, walk the guided chain — and the JSON is done for you.

🪄 Coming soon to the App Store

Why iYegen?

🔗

Paste a URL

An invisible in-app browser loads the page with JavaScript, exactly like Yealico will see it.

🪄

Tap the wand

Index, detail, video or gallery — iYegen measures the page and suggests the right structure.

📦

Import the JSON

A complete site rule — categories, tags, pagination, detail and video — ready to import into Yealico.
